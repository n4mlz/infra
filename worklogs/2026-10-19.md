# 2026-10-19 Talos バージョン更新

## 実施内容

- Talos の目標バージョンを v1.14.4 に設定。
- 全7ノードを v1.11.6、v1.12.12、v1.14.4 の順で更新した。Talos Factory schematic はリポジトリの `talos/schematics.yaml` から生成した。
- cp-03 の古い etcd 状態を解消するため、利用者の指示に基づき EPHEMERAL パーティションを消去して再参加させた。バックアップは取得していない。
- `talos:upgrade-schematic` に対象バージョン指定と、すでに目標バージョンのノードをスキップする処理を追加した。
- devcontainer に `yq` を追加し、`talosctl` を Talos v1.14.4 に合わせた。

## 確認結果

- cp-01〜03、wk-01〜04 はすべて Talos v1.14.4。
- etcd は control plane 3台で構成され、全メンバーが voter (`LEARNER=false`)。
- Kubernetes Node 7台すべて Ready。実クラスタの Kubernetes バージョンは v1.32.0。
- cp-01 で `iscsi-tools` v0.2.0 と `util-linux-tools` 2.42.2 を確認した。
- バージョン更新前後に etcd、control plane Pod、CoreDNS、全ノード Ready の health check を実施した。
- `talconfig.yaml` の Kubernetes 目標は v1.34.1 だが、今回 Kubernetes の更新は行っておらず、実クラスタは v1.32.0 のまま。

## 互換性調査

- Talos v1.14 は v1.12.0 以降から更新でき、Kubernetes v1.32.0 以降に対応する。
- Talos v1.11 は v1.9.0 以降から更新できるため、今回の中間バージョンを v1.11.6、v1.12.12 とした。
- 参照: [Talos v1.14 compatibility](https://pkg.go.dev/github.com/siderolabs/talos/pkg/machinery/compatibility/talos114)、[Talos v1.11 compatibility](https://pkg.go.dev/github.com/siderolabs/talos/pkg/machinery/compatibility/talos111)、[Talos v1.14.4 release](https://github.com/siderolabs/talos/releases/tag/v1.14.4)
