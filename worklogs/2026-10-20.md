# 2026-10-20 Kubernetes 基盤設定

## Tailscale Kubernetes Operator の GitOps 定義

- 公式 stable Helm repository の chart `1.104.1` を Flux HelmRelease として追加した。
- OAuth client ID / secret は 1Password item から External Secrets Operator が `tailscale/operator-oauth` Secret に同期する設計とし、Helm values や Git に credential 値を含めない。
- Operator namespace に 1Password store 利用 label と、Operator が生成する privileged ingress proxy 用の Pod Security 設定を追加した。
- Controller / network architecture / credential handling / runbook の日本語ドキュメントを更新し、既存 subnet router との役割の違い、Tailnet tag policy、OAuth scope、Service 公開方法を記録した。
- 公式仕様確認: [Tailscale Operator install](https://tailscale.com/docs/kubernetes-operator/install-operator)、[chart index](https://pkgs.tailscale.com/helmcharts/index.yaml)、[L3 ingress](https://tailscale.com/docs/kubernetes-operator/ingress/expose-workload-to-tailnet-l3)。
- クラスタへの適用は行っていない。Tailnet policy と 1Password OAuth item の作成が前提となる。

## Gateway 証明書の追加

- apex と wildcard subdomain の DNS-01 Certificate を追加し、共有 Gateway に対応する HTTP/HTTPS listener を追加した。ExternalDNS の対象 domain filter を拡張した。
- Cloudflare token の zone 権限を確認し、既存 DNS record の ownership 移行方法を Gateway runbook に記録した。
- Gateway config の Kustomize build と API server dry-run を実行した。証明書発行は Flux が変更を適用した後に確認する。
