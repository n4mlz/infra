# 2026-11-20〜21 control plane のメモリ削減

- cp-01〜cp-03 を各 8 GiB から 4 GiB に変更し、VM 全体の割り当てを 40 GiB から 28 GiB に削減した。QEMU Guest Agent が Talos に含まれず Proxmox からの shutdown が失敗するため、各 VM を `talosctl shutdown` で停止してから OpenTofu で適用した。
- OpenTofu の state と `terraform.tfvars` を cosmos から rose に移した。今後は rose の state を使う。cosmos に残る state は更新されない。
